# Installing byd-dolphin-hacking

> Reverse engineering the BYD Dolphin head unit — CAN bus, AVAS, NFC keys, OTA, and more. DiLink 3 / Android 10.

Source: kitploit directory; upstream [`wheregoes/byd-dolphin-hacking`](https://github.com/wheregoes/byd-dolphin-hacking).

## Prebuilt / releases

Check [upstream releases](https://github.com/wheregoes/byd-dolphin-hacking/releases) for binaries.

## Any other Linux distro

```bash
git clone https://github.com/wheregoes/byd-dolphin-hacking.git
cd byd-dolphin-hacking
make
sudo make install    # if no install target, copy binary to /usr/local/bin
```
