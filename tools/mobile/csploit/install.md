# Installing csploit

APK sources (pick one):

```bash
# official F-Droid catalog
# org.csploit.android in the F-Droid client

# GitHub releases (also carries pre-releases)
https://github.com/cSploit/android/releases

# fresh nightly builds
# http://www.csploit.org/downloads
```

Requirements on the device: a **rooted** Android 2.3+ (Magisk-era SuperSU successors usually work; the app asks for root at launch), a **full BusyBox installation** (every applet, not the partial install), and SuperSU as the permission manager. Note the project is end-of-life — on recent Android versions expect breakage; test on your actual device/ROM before an engagement.
