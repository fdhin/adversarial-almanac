# packet-sniffer

> Former name of RootWire — canonical note: [[rootwire]].

`packet-sniffer` was the original name of eonraider's GNU/Linux traffic monitor (a Python/scapy sniffer when the note was created). The project renamed itself to RootWire — repository `EONRaider/RootWire` (the old `eonraider/packet-sniffer` URL redirects there), CLI `rootwire`, PyPI package `rootwire` — and was substantially rewritten (raw-socket capture, pcap replay, NDJSON output). It is one tool, not two: the full reference with use cases lives in [[rootwire]], and installation instructions in its install note.
