# sqlpowerinjector

> .NET 1.1 GUI workbench for finding and exploiting SQL injection on a web page, with multithreaded blind-injection automation.

## What it's for

SQL Power Injector (sqlpowerinjector.com, SourceForge project `spinj`, v1.2) is a Windows application, created in .NET 1.1, that helps a penetration tester find and exploit SQL injection on a web page. It works in a normal (inline) mode — essentially the SQL command placed into the injected parameter, usable against any existing DBMS — and offers automated modes compliant with SQL Server, Oracle, MySQL, Sybase/Adaptive Server and DB2. Its stated main strength is the multithreaded automation of the injection: tedious, time-consuming queries can be automated and tuned to return exactly the wanted data, which pays off most in blind SQL injection, where every value has to be inferred bit by bit rather than read from an error or union output. A mid-2000s point-and-click assistant of the pre-sqlmap era; the original site is gone, and the SourceForge package is the reference distribution. GUI application with no command-line interface.

GitHub: third-party mirror of the SQL Power Injector v1.2 distribution (SourceForge project spinj).
