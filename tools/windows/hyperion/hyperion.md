# hyperion

> Kali's packaging of the Hyperion runtime PE-crypter, version 2.0 (32-bit only).

Same tool as [[hyperion-crypter]] — the Hyperion runtime encrypter for portable executables by Christian Ammann (phobosys.de), distributed by nullsecurity. The Kali `hyperion` package builds the older 2.0 release, which encrypts 32-bit executables only; the current upstream release is 2.3.1 with both 32- and 64-bit support, packaged by BlackArch as `hyperion-crypter`. Usage, flags and the tool's lineage are documented on the [[hyperion-crypter]] note.
