# eraser

> Secure-deletion utility for Windows that overwrites files and free disk space with selectable erase patterns.

## What it's for

Eraser (Heidi Computers Ltd) removes sensitive data from a Windows machine for good: instead of just unlinking files, it overwrites them — and the drive's free space, where deleted data lingers — several times with carefully selected patterns (predefined standards such as Gutmann or US DoD schemes, or custom-defined ones) so the original content cannot be recovered by undelete tools or forensic examination. Everyday use is through its graphical interface: on-demand erasing of files, folders and unused disk space from Windows Explorer's context menu, plus a scheduler that runs recurring erase jobs automatically. It targets files and free space on live filesystems — it is not a whole-disk wiping utility, and the 6.x line ships no command-line interface.
