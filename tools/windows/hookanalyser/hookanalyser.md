# hookanalyser

> Freeware Windows toolkit combining API hooking, memory inspection and malware/threat-intelligence lookups.

## What it's for

Hook Analyser (Beenu Arora) is a menu-driven Windows application for malware analysis and cyber-threat-intelligence triage. From its numbered menu you can attach to a running process and hook a chosen API, search its memory for a byte pattern, and dump buffers — the classic manual-unpacking workflow — plus run static analysis of suspicious files (signature-based malware detection, Authenticode certificate extraction, XML reports), query public sources for keyword- and IP-based malware intelligence in a dashboard, and batch-analyze every file in a directory. The community edition is free for non-commercial use only. The project is dead: the author's blog has been removed and the download link in the packaging is a defunct Google Docs URL, and the application exposes no documented command-line interface, so this entry is description-only — run the executable and drive it from its interactive menu.
