# Installing sopa

> Scriptable Golang client for Active Directory Web Services (ADWS): query, edit, create and delete AD objects over port 9389.

Source: hacktricks feed; upstream [`Macmod/sopa`](https://github.com/Macmod/sopa).

## Install with Go

```bash
go install github.com/Macmod/sopa/cmd/sopa@latest
```
