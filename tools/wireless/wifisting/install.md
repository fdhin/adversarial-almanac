# Installing wifisting

> GTK4 wireless security toolkit for Linux. 58 modules covering Wi-Fi, Bluetooth, RF and other wireless protocols as well as router-side and network MITM in one place. Built to tell you when…

Source: kitploit directory; upstream [`yslxotwod/wifisting`](https://github.com/yslxotwod/wifisting).

## Prebuilt / releases

Check [upstream releases](https://github.com/yslxotwod/wifisting/releases) for binaries.

## Any other Linux distro

```bash
git clone https://github.com/yslxotwod/wifisting.git
cd wifisting
make
sudo make install    # if no install target, copy binary to /usr/local/bin
```
