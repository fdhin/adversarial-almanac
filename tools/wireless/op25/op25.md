# op25

> Software-defined receiver that decodes APCO P25 public-safety radio (plus DMR, SmartZone and NBFM in this fork) from an SDR dongle.

## What it's for

op25 turns a cheap SDR (e.g. an RTL-USB dongle) into a monitoring receiver for APCO Project 25 digital radio systems: it demodulates the signal, decodes Phase 1/Phase 2 voice and data, follows trunked systems from their control channel, and plays audio while showing live system state in a curses or HTTP terminal. The boatbod fork packaged here (diverged from the original osmocom op25 since 2019) adds talkgroup black/whitelists with dynamic reload, talkgroup priority and preemption, tgid/radio-id tagging, Icecast streaming metadata, symbol capture/replay, and — through `multi_rx.py` — concurrent multi-system operation including DMR and Motorola SmartZone. Voice decryption for ADP/RC4, DES-OFB and AES-256 works only with a key you supply; it does not recover unknown keys. The practical entry points are `rx.py` (single system, trunk.tsv configured) and `multi_rx.py` (JSON configured) under `op25/gr-op25_repeater/apps/`.

## Typical use cases

### Follow a P25 trunked system and hear audio

Point rx.py at a dongle and a trunking configuration.

```
./rx.py --args 'rtl=0' -S 2400000 -q 0 -o 8000 -N 'LNA:46' -T trunk.tsv -V -v 1 -U
```

Outcome: opens the RTL dongle at 2.4 Ms/s with PPM correction and DC offset, locks onto the control channel listed in `trunk.tsv`, and follows voice grants for non-blacklisted talkgroups; `-V` enables the AMBE vocoder and `-U` the built-in UDP audio player, while a curses terminal shows system/talkgroup state and accepts hold, blacklist and priority keys.

### Run the browser terminal instead of curses

Drive the receiver from a web page with websocket audio.

```
./rx.py --args 'rtl=0' -S 2400000 -T trunk.tsv -V -2 --tdma-cc -l http:127.0.0.1:8080
```

Outcome: same decode chain, but the terminal is an HTTP server on port 8080 — open it in a browser for the remote-control UI — and `-2 --tdma-cc` enables Phase 2 TDMA voice plus TDMA control channel decoding.

### Monitor several systems concurrently with multi_rx.py

Decode P25, DMR and analog channels at the same time from one or more dongles.

```
./multi_rx.py -c multi_rx.json -v 1
```

Outcome: builds the receiver graph from the JSON configuration (devices, channels, trunking, terminal, audio), running all configured systems full-time rather than scanning between them — the `multi_rx.json` sample shipped in the apps directory is the template to copy and edit.

### Skip encrypted talkgroups

Keep monitoring on systems that mix clear and encrypted traffic.

```
./rx.py --args 'rtl=0' -S 2400000 -T trunk.tsv -V -U --crypt-behavior 1
```

Outcome: encrypted calls are silenced (`--crypt-behavior 1`) rather than played as noise — use `--crypt-behavior 2` (the default) to skip them entirely, or `-k <keys.json>` to decrypt protocols you hold keys for (ADP/RC4, DES-OFB, AES-256).
