# Installing wifit3

> Wifite but USB-only & cross-platform.

Source: kitploit directory; upstream [`derv82/wifit3`](https://github.com/derv82/wifit3).

## Prebuilt / releases

Check [upstream releases](https://github.com/derv82/wifit3/releases) for binaries.

## Any other Linux distro

```bash
git clone https://github.com/derv82/wifit3.git
cd wifit3
python3 -m pip install --user -r requirements.txt  # or per README
```
