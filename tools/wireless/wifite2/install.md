# Installing wifite2

> Rewrite of the popular wireless network auditor, 'wifite'

Source: kitploit directory; upstream [`derv82/wifite2`](https://github.com/derv82/wifite2).

## Prebuilt / releases

Check [upstream releases](https://github.com/derv82/wifite2/releases) for binaries.

## Any other Linux distro

```bash
git clone https://github.com/derv82/wifite2.git
cd wifite2
python3 -m pip install --user -r requirements.txt  # or per README
```
