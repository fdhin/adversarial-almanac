# wifite2

> The original author's Python rewrite of wifite — now superseded by the maintained fork and by wifit3.

## What it's for

This is derv82's wifite2, the complete Python rewrite of his 2011 wifite (Python 2) automating WEP, WPS and WPA/WPA2 auditing on top of aircrack-ng. Development has moved on in two directions, and the repo's own README points to both: the maintained, feature-expanded continuation (WPA3/SAE, PMKID, evil twin, dual adapters) lives at kimocoder/wifite2 and is what distros package as the `wifite` command — that note is [[wifite]] and carries all use cases — and the author's new USB-only cross-platform generation is [[wifit3]]. Treat this entry as the lineage record for the original v2 repository; run nothing from it directly unless you specifically want the last derv82-era snapshot.
