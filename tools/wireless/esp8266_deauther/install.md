# Installing esp8266_deauther

> Affordable WiFi hacking platform for testing and learning

Source: kitploit directory; upstream [`spacehuhntech/esp8266_deauther`](https://github.com/spacehuhntech/esp8266_deauther).

## Prebuilt / releases

Check [upstream releases](https://github.com/spacehuhntech/esp8266_deauther/releases) for binaries.

## Any other Linux distro

```bash
git clone https://github.com/spacehuhntech/esp8266_deauther.git
cd esp8266_deauther
make
sudo make install    # if no install target, copy binary to /usr/local/bin
```
