# auto-xor-decryptographyr-git

> ArchStrike package name for MRG Effitas' automatic XOR decryptor — the same tool as [[auto-xor-decryptor]].

## What it's for

This is the ArchStrike packaging (`-git`) of `auto_xor_decryptor.py` from MRG Effitas' `scripts` repository — the identical upstream (same version `7.2eb176d`) that BlackArch packages as `auto-xor-decryptor`. It automatically finds short XOR keys in an XOR-encrypted binary and decrypts it; if the key is already known it can be supplied in hex or ASCII. The upstream repository is gone; see the full note for verified usage, examples, and the archived-source evidence.
