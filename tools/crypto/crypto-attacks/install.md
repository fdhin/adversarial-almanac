# Installing crypto-attacks

> Python implementations of cryptographic attacks and utilities.

Source: kitploit directory; upstream [`jvdsn/crypto-attacks`](https://github.com/jvdsn/crypto-attacks).

## Prebuilt / releases

Check [upstream releases](https://github.com/jvdsn/crypto-attacks/releases) for binaries.

## Any other Linux distro

```bash
git clone https://github.com/jvdsn/crypto-attacks.git
cd crypto-attacks
python3 -m pip install --user -r requirements.txt  # or per README
```
