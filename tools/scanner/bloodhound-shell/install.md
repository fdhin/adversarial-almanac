# Installing bloodhound-shell

> An interactive command-line shell for BloodHound API.

Source: kitploit directory; upstream [`kr0no/bloodhound-shell`](https://github.com/kr0no/bloodhound-shell).

## Prebuilt / releases

Check [upstream releases](https://github.com/kr0no/bloodhound-shell/releases) for binaries.

## Any other Linux distro

```bash
git clone https://github.com/kr0no/bloodhound-shell.git
cd bloodhound-shell
python3 -m pip install --user -r requirements.txt  # or per README
```
