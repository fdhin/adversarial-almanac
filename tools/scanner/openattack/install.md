# Installing openattack

> An Open-Source Package for Textual Adversarial Attack.

Source: kitploit directory; upstream [`thunlp/openattack`](https://github.com/thunlp/openattack).

## Prebuilt / releases

Check [upstream releases](https://github.com/thunlp/openattack/releases) for binaries.

## Any other Linux distro

```bash
git clone https://github.com/thunlp/openattack.git
cd openattack
python3 -m pip install --user -r requirements.txt  # or per README
```
