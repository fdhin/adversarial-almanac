# redteam-tools

> Curated collection of 150+ red team tool write-ups and tradecraft tips with links to the original sources.

## What it's for

A reference repository, not software: A-poc's RedTeam-Tools is a large curated
markdown catalogue of tools and techniques useful for red teaming, grouped into
sections such as Red Team Tips (19 one-liner tradecraft notes), C2, initial
access, phishing, evasion, and Active Directory tooling. Each entry explains
what the tool or technique does, shows a short example, and credits the
original author or tweet it came from (many entries by @Alh4zr3d, @pr0xylife,
@malmoeb and others). There is nothing to install or run — the repository's
content is the deliverable — so this note intentionally ships no example
commands. Use it to discover tools worth adding to an engagement toolkit or to
find technique inspiration (HTML smuggling variants, Defender signature
deletion, AppLocker enumeration, live-off-the-land port scans); a companion
BlueTeam-Tools repository covers the defensive side.

README); it is a links-and-notes collection with no CLI, so this note is
description-only.*
