# Installing ankosint

> AnkOsint Open Source Intelligence Tool

Source: kitploit directory; upstream [`dogucyber/ankosint`](https://github.com/dogucyber/ankosint).

## Prebuilt / releases

Check [upstream releases](https://github.com/dogucyber/ankosint/releases) for binaries.

## Any other Linux distro

```bash
git clone https://github.com/dogucyber/ankosint.git
cd ankosint
python3 -m pip install --user -r requirements.txt  # or per README
```
