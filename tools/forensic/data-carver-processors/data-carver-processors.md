# data-carver-processors

> Legacy "Data Carver Processors" toolkit from Citadel Systems — carving processors for JPEG, PDF and video files.

## What it's for

Data Carver Processors (DCP) is a set of data-carving processors for JPEG, PDF and video files, once distributed by Citadel Systems and carried in the Pentoo overlay as `app-forensics/data-carver-processors`. The upstream site (citadelsystems.net) is dead and not preserved in public web archives, the ebuild is no longer present in current package trees, and no runnable interface or command documentation could be located or verified — so no usage examples are given here. Treat this as a historical catalog entry from the carving-tool era (contemporary with tools like Foremost and Scalpel) rather than a usable tool.
