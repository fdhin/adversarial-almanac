# linen

> EnCase's LinEn: the closed-source Linux acquisition console for imaging disks in EnCase evidence format.

## What it's for

`linen` (LinEn) is the Linux edition of the EnCase acquisition program from Guidance Software (now OpenText): a single proprietary executable used to boot a subject system from live Linux media and image its disks — locally or over the network to an EnCase examiner — in EnCase evidence (E01) format. It is distributed only under the vendor's license agreement (the package is fetch-restricted; see `install.md`), and no public source or reference command-line documentation exists, so no verifiable CLI examples can be given for it here.
