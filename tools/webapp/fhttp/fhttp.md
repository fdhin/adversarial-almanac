# fhttp

> A Perl/GTK2 graphical toolkit for HTTP attacks: request crafting, a debugging proxy, proxy chaining and evasion rules.

## What it's for

FHTTP ("FHTTP Kit", v1.3, by Xianur0 / Oscar García López, 2011) is a GUI framework for HTTP-related attacks. From its GTK interface you build and replay requests, run traffic through an integrated debugging and rewriting proxy, chain proxies, apply evasion rules from its `reglas.txt` rules file, fingerprint targets, and run dictionary attacks through its bundled modules; runtime configuration lives in `config.fhttp` and the interface is bilingual (Spanish/English). Everything is driven from the graphical front end — it exposes no command-line interface, so no runnable examples can be documented. It is legacy Perl 5/GTK2 era software, kept for reference rather than daily use.
