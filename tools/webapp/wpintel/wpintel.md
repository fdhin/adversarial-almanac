# wpintel

> Chrome extension that profiles and vulnerability-checks the WordPress site in the active tab.

## What it's for

WPintel (by Tuhinshubhra) is a Google Chrome extension for WordPress information gathering and vulnerability scanning from the browser. Its toolbar icon changes color to indicate whether the currently visited site runs WordPress; clicking it offers scans that detect the WordPress core version and its known vulnerabilities, enumerate users, list installed themes and plugins, find full-path disclosure, and check whether user registration is open. The target can be switched from the extension popup without navigating to it. It is purely a browser GUI tool — there is no command-line interface, and the packaged `wpintel` launcher script only opens the extension's Chrome Web Store listing in a Chromium app window.
