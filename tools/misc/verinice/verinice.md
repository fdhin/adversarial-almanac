# verinice

> Open-source GRC suite for building and operating an information security management system against ISO 27001, BSI IT-Grundschutz and similar standards.

## What it's for

verinice is a Java-based governance/risk/compliance application for CISOs and
IT security officers. It models an ISMS as a dynamic object graph — assets,
threats, controls, incidents, audit findings — with standards such as ISO
27001, BSI IT-Grundschutz or IDW PS 330 built in or importable, and tracks
compliance over time. It runs as an Eclipse Rich Client Platform GUI backed by
an application server and a shared database (PostgreSQL, Apache Derby or
Oracle), and produces customizable BIRT reports as PDF, HTML or CSV. This is
interactive client/server software launched via the `verinice` desktop
launcher; it documents no command-line workflow, so it cannot be driven from a
shell the way the vault's CLI tools can.
