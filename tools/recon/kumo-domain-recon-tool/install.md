# Installing kumo-domain-recon-tool

> Kumo 蜘蛛 is a domain OSINT & web security reconnaissance framework. Drop a domain,  get everything back in real time across 29 parallel modules: DNS, open ports, leaked credentials,…

Source: kitploit directory; upstream [`karim852/kumo-domain-recon-tool`](https://github.com/karim852/kumo-domain-recon-tool).

## Prebuilt / releases

Check [upstream releases](https://github.com/karim852/kumo-domain-recon-tool/releases) for binaries.

## Any other Linux distro

```bash
git clone https://github.com/karim852/kumo-domain-recon-tool.git
cd kumo-domain-recon-tool
python3 -m pip install --user -r requirements.txt  # or per README
```
