# ipv666

> IPv6 host discovery toolkit that finds live addresses in the global IPv6 space or a narrow range using statistical models instead of brute force.

## What it's for

Finding live hosts in IPv6, where a /64 cannot be brute-forced. `ipv666` generates plausible candidate addresses from a probabilistic clustering model (trained on real observed IPv6 layouts), ICMP-pings them, detects and skips aliased networks where every address answers, and writes the confirmed hits to a file. Reach for it when you know a target has IPv6 but have no seed addresses; it works out of the box with a bundled default model. It does not scan IPv4 and is not a port scanner — it only finds live addresses. Note that scanning generates substantial ICMP traffic (bandwidth is capped via a flag, default 20 Mbps) and the tool periodically offers to upload discovered addresses to the authors' public ipv6.exposed database (decline, or pass `-f`/`--force` to suppress prompts in unattended runs).

## Typical use cases

### Discover live IPv6 hosts in a target range

```
ipv666 scan discover -b 10M -n 2001:db8::/32 -o addresses.txt
```

Outcome: the main workhorse — generates candidates from the default model, pings them within the 10 Mbps cap, tests ranges that answer for aliasing, and writes confirmed live addresses to `addresses.txt` (use `-t bin` for binary output). With no `-n` it scans the global IPv6 space (2000::/4). Expect heavy ICMP volume; choose `-b` with care.

### Test whether a range is aliased

```
ipv666 scan alias -n 2001:db8:1234:5678::/96 -l debug
```

Outcome: pings the range and reports whether every host answers (an aliased network — a common ISP/intrusion-detection decoy), binary-searching for the exact aliased boundary if so. Add `-b` to cap bandwidth. Use before trusting any scan results in that range.

### Generate candidate addresses from the model

```
ipv666 generate addresses -c 500000 -n 2001:db8::/32 -o candidates.txt
```

Outcome: writes 500,000 model-predicted addresses in the given range to `candidates.txt` (default one million, global space) without scanning anything — feed them to your own scanner, or use `-m model` to generate from a custom model instead of the bundled one.

### Train a model on known addresses, then reuse it

```
ipv666 generate model -i known_addrs.txt -o custom.model
```

Outcome: builds a new predictive clustering model from a file of IPv6 addresses you already know for the target's addressing style, written to `custom.model`. Pass it back via `generate addresses -m custom.model` for range-specific candidates.

### Blacklist aliased ranges and scrub an address list

```
ipv666 generate blacklist -i addrranges.txt
ipv666 clean -i discovered.txt -o cleaned.txt
```

Outcome: the first command adds newline-delimited CIDR ranges from `addrranges.txt` to the aliased-network blacklist that `scan discover`, `scan alias` and `clean` auto-load; the second removes every address in `discovered.txt` that falls inside a blacklisted range and writes the survivors to `cleaned.txt` — the standard way to deflake results from other IPv6 sources.
