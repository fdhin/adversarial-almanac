# Installing tookie-osint

> Tookie is a advanced OSINT information gathering tool that finds social media accounts based on inputs.

Source: kitploit directory; upstream [`alfredredbird/tookie-osint`](https://github.com/alfredredbird/tookie-osint).

## Prebuilt / releases

Check [upstream releases](https://github.com/alfredredbird/tookie-osint/releases) for binaries.

## Any other Linux distro

```bash
git clone https://github.com/alfredredbird/tookie-osint.git
cd tookie-osint
python3 -m pip install --user -r requirements.txt  # or per README
```
