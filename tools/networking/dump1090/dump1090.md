# dump1090

> Mode S / ADS-B decoder for RTL-SDR dongles: live aircraft table, Google-Map web view, and TCP streams.

## What it's for

dump1090 decodes 1090 MHz Mode S / ADS-B transmissions received on an
RTL-SDR dongle and presents live aircraft data several ways at once: an
interactive console table refreshing as messages arrive, an embedded HTTP
server showing detected aircraft on a map, and network outputs (raw
in/out on TCP 30001/30002, AVR-format MSG stream on TCP 30003). It does
weak-message decoding with single-bit CRC correction, CPR position
decoding, and can decode offline from a recorded IQ file. This note tracks
the MalcolmRobb fork of antirez's original dump1090 that BlackArch
packages — not the separate dump1090-mutability fork. It is purely a
receiver/decoder, useful for SDR experimentation and verifying aircraft
data feeds; it transmits nothing.

## Typical use cases

### Live decode with the network map

Run against an attached dongle and watch aircraft in the browser.

```
dump1090 --interactive --net
```

Outcome: shows a refreshing aircraft table in the terminal and opens the
network outputs, including the map at `http://localhost:8080` and raw
streams on ports 30001/30002/30003; connect an external decoder to the TCP
ports to consume the feed.

### Raw hex output only

Minimal output for piping into other tools.

```
dump1090 --raw
```

Outcome: prints each decoded Mode S message as hex (`*8D451E8B99019699C00B0A81F36E;`)
on stdout with no tables or formatting.

### Decode a recorded IQ capture offline

Analyze a capture made with rtl_sdr, no dongle needed.

```
rtl_sdr -f 1090000000 -s 2000000 -g 50 - > capture.bin
dump1090 --ifile capture.bin
```

Outcome: decodes 8-bit IQ samples at 2 MHz from the file exactly as if
they came from the dongle, reproducing the same aircraft output for the
capture window.

### Aggressive mode for weak signals

Trade CRC strictness for range on marginal captures.

```
dump1090 --interactive --aggressive
```

Outcome: relaxes checksum handling so more messages (including ones with
uncorrectable errors) are decoded, extending visible range at the cost of
possible false positives — useful only where the antenna sees few aircraft.
