# Installing dheater

Python 3.9+; published on PyPI (pulls in CryptoLyzer automatically):

```bash
pip install dheater
```

Development version from the GitLab home (the GitHub repo under `c0r0n3r` mirrors it):

```bash
pip install git+https://gitlab.com/dheatattack/dheater.git
```

The installed console command is `dheat`.
