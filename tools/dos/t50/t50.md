# t50

> High-rate multi-protocol IPv4 packet injector for network stress testing, with a full man page (t50.8).

## What it's for

T50 (originally by Nelson Brito, maintained by Frederico Pissarra) injects
packets for over a dozen protocols — ICMP, IGMPv1/v3, TCP, UDP, EGP, RIPv1/v2,
DCCP, RSVP, GRE, IPSec (AH/ESP), EIGRP and OSPF — either one at a time or all
sequentially ("the T50 protocol"), and can encapsulate any of them in GRE.
Its own man page stresses it is a stress-testing tool for infrastructure
(rate-limiting, load balancers, firewalls), not a general-purpose DoS weapon:
on gigabit Ethernet it can push over 1,000,000 packets per second of TCP SYN.
IPv4 only, root required. Run `t50 -h` for the full option list with defaults
and `man 8 t50` for the shipped manual.

## Typical use cases

### List the injectable protocols

Confirm what this build supports before designing a test.

```
sudo t50 -l
```

Outcome: prints the banner and a numbered list of the supported protocols
for use with `--protocol` (ICMP through OSPF, plus `t50` for all of them).

### Send a fixed packet count to one host

Bounded injection run — the safe default shape for a first test.

```
sudo t50 198.51.100.10 --threshold 500
```

Outcome: sends exactly 500 packets (default protocol TCP) to the target and
exits, printing per-protocol statistics on completion. Without `--threshold`
the default is 1000 packets.

### Flood a subnet with TCP SYN packets

Unbounded run against a whole address range to stress a gateway or firewall.

```
sudo t50 198.51.100.0/24 --flood
```

Outcome: injects packets continuously (the man page cites 1M+ pps SYN on
gigabit) to every address in the CIDR until you press Ctrl+C. `--flood`
cannot be combined with `--threshold`.

### Run every protocol shuffled, in turbo mode

Exercise a device's full parsing path rather than a single protocol stack.

```
sudo t50 198.51.100.0/24 --flood -p t50 --shuffle --turbo
```

Outcome: injects all supported protocols in random order (a child process
is spawned for the higher `--turbo` rate) until interrupted; the target sees
mixed-protocol traffic across the whole subnet.

### Spoof the source address

Test source-based filtering or anti-spoofing controls on the path.

```
sudo t50 --flood -s 198.51.100.77 198.51.100.10
```

Outcome: floods the target with packets whose IP source address is the
spoofed 198.51.100.77 (default is a random source per packet), letting you
verify whether upstream uRPF/anti-spoof rules drop them.
