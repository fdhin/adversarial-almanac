# cai

> Cybersecurity AI — Alias Robotics' framework for building LLM-driven security agents; archived as a research artifact after establishing "Cybersecurity AI" as a research domain.

*No corpus evidence — derived from upstream documentation. The repository is archived and read-only: this note describes what the framework was, not a maintained tool.*

## What it's for

Historical interest and reference. CAI was a lightweight open-source framework for building and deploying AI-powered cybersecurity agents — the design that made autonomous security agents a research field rather than a demo, with 18 accompanying papers from Alias Robotics. Its final source tree is preserved read-only as a research artifact, and development moved to Alias Robotics' successor ("Cybersecurity Superintelligence"). For current work, treat it as a corpus of agent architectures to read (planning loops, tool use, benchmarking of security agents), not as a tool to deploy; no command usage is documented here because the archived README intentionally carries research narrative rather than a maintained CLI reference.
