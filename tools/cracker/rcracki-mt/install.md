# Installing rcracki-mt

> A tool to perform rainbow table attacks on password hashes. It is intended for indexed/perfected rainbow tables, mainly generated by the distributed project www.freerainbowtables.com.

Recipe source of truth: BlackArch [`PKGBUILD`](https://github.com/BlackArch/blackarch/tree/master/packages/rcracki-mt) (version `0.7.0`, license GPL-2.0-or-later).

## Arch / BlackArch

```bash
sudo pacman -S rcracki-mt    # needs the [blackarch] repo enabled
```

## Kali / Debian-based

```bash
sudo apt install rcracki-mt    # Kali package version 0.7.0-1kali5
```

## Any Linux distro

**From source (needs gcc + make):**

**Source:** download the release from the [upstream site](https://rcracki.sourceforge.net/) (the recipe uses a versioned archive).

```bash
make -j$(nproc)
sudo make install    # if no install target, copy the binary to /usr/local/bin
```

## Dependencies (from recipe)

- **System libraries** (Arch name — translate for your distro):
  - `openssl` — Debian libssl-dev / Fedora openssl-devel

## Exact build steps from the recipe

```bash
cd "${pkgname//-/_}_${pkgver}_src/${pkgname//-/_}"

  make
```

## Installed layout (per recipe)

- No `/usr/bin` entry — scripts run from the source/`/usr/share` directory
