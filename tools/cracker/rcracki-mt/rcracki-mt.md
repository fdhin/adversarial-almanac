# rcracki-mt

> Multi-threaded rainbow-table cracker for indexed/perfected tables (`.rti`/`.rt`).

## What it's for

Cracks password hashes with precomputed rainbow tables instead of raw brute force. It is the improved, multi-threaded fork of RainbowCrack ("rcracki" by Martin Westergaard Jørgensen, multi-threaded by neinbrucke), built for the indexed, perfected `.rti` tables generated by the distributed Free Rainbow Tables project, though it also reads original `.rt` tables. Supported algorithms include LM, NTLM, MD2, MD4, MD5, DoubleMD5, SHA1, RIPEMD160, MSCACHE, MySQL323, MySQLSHA1, PIX, LMCHALL/HALFLMCHALL/NTLMCHALL and ORACLE. Input can be a single raw hash (`-h`), a hash list file (`-l`), a pwdump file (`-f`) or a Cain `.lst` file (`-c`); for pwdump/Cain input holding both LM and NTLM hashes it cracks the LM half and then restores the correct letter case using the NTLM hash. It does not generate tables — you need tables from a generator or a download; it only runs the lookup side. Sessions checkpoint precalculation and progress to disk so a run interrupted with Ctrl+C can resume cheaply.

## Typical use cases

### Crack a single hash against local tables

Look up one raw hash in a directory of tables.

```
rcracki_mt -h 5d41402abc4b2a76b9719d911017c592 -t 4 ./tables/md5
```

Outcome: recursively scans `./tables/md5` for `.rti`/`.rt` files, cracks with four threads, and prints each found plaintext next to its hash plus run statistics; the hash disappears from the working queue once cracked.

### Crack a list of hashes

Process many hashes at once from a file.

```
rcracki_mt -l hashes.txt -o found.txt ./tables/*
```

Outcome: reads one hash per line from `hashes.txt`, writes every cracked `hash:plaintext` result to `found.txt` immediately as it is found — useful for long runs — and prints a summary when all tables have been checked.

### Attack a pwdump dump

Crack LM/NTLM hashes straight from a credential dump.

```
rcracki_mt -f dump.txt -t 8 -o results.txt ./tables/lm ./tables/ntlm
```

Outcome: takes the dump file in pwdump format, cracks the LM hashes first, then case-corrects each recovered uppercase password against the paired NTLM hash (with Unicode correction attempted when casing fails), and logs results to `results.txt`.

### Resume an interrupted session

Continue a run that was stopped partway.

```
rcracki_mt -r -s mysession
```

Outcome: reloads the precalculation data and progress stored under session name `mysession` and resumes cracking where the Ctrl+C stopped it, instead of redoing the disk- and CPU-heavy precalculation. Add `-k` on the original run to keep precalculation files after completion for later reuse.
